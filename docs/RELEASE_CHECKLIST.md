# Release checklist
- Verify all required CI jobs on Linux, Windows and macOS.
- Review dependency lockfile, licenses, security findings and package contents.
- Test clean installation and CLI invocation outside the source repository.
- Verify generated files, existing-file conflicts and symlink handling.
- Run independent review and obtain maintainer approval.
- Record known limitations and actual test evidence.
- Publish only after approval; never claim certification or universal agent compliance.
