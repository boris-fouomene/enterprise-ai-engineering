# Enterprise AI Engineering

A standards-driven engineering framework for humans and AI agents, independent of programming language, model and vendor.

**Status:** initial foundation; not a certified compliance product.

Start with [AGENTS.md](AGENTS.md), the [engineering standards](standards/ENGINEERING.md), and the [engineering loop](workflows/ENGINEERING_LOOP.md). Humans and agents follow the same rules. Automated checks provide evidence, not a guarantee of correctness.

The roadmap will introduce a portable CLI, policy profiles, adapters and reproducible benchmarks. No employer code or confidential material belongs in this project.
