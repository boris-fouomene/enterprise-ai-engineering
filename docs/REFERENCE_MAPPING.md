# Reference mapping
This is an informative thematic mapping, not a control-by-control audit or certification.

- NIST SP 800-218 SSDF 1.1: organizational readiness (REQ, GOV), protection of software (SEC, SUP), secure implementation (CODE, ARCH, TEST), vulnerability response (SEC-04, OPS-02). https://csrc.nist.gov/pubs/sp/800/218/final
- OWASP ASVS 5.0.0: use as a separate detailed verification baseline for web applications and services, especially API, DATA and SEC rules. https://asvs.owasp.org/
- NIST SP 800-218A concerns development of generative AI and dual-use foundation models; apply it where relevant, not automatically to every project using a coding assistant. https://csrc.nist.gov/projects/ssdf

Projects must choose applicable external requirements and track evidence separately. The engineering catalog does not reproduce these standards or substitute for their assessment processes.
